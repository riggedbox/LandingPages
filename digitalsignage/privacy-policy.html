2. Data yang kami proses

  • Access token Instagram yang dimasukkan operator untuk menghubungkan akun profesional.

3. Cara penggunaan data

Data digunakan untuk menghubungkan akun, memvalidasi akses, mengambil media yang diminta, menampilkan playlist, menjaga keamanan aplikasi, memberikan dukungan, dan memenuhi kewajiban hukum. Kami tidak menjual data pribadi, tidak menggunakan data Instagram untuk iklan, dan tidak menggunakan data untuk membangun profil pengguna.

4. Penyimpanan dan keamanan

Dalam konfigurasi local-first saat ini, kredensial disimpan oleh backend lokal dalam file terenkripsi. Browser tidak menerima access token privat. Media dan konfigurasi dapat tersimpan pada perangkat tempat aplikasi dijalankan. Anda bertanggung jawab mengamankan perangkat, jaringan, backup, dan akses operator.

5. Berbagi data

Layanan berkomunikasi dengan layanan resmi Meta/Instagram untuk mengambil data yang diminta. Kami tidak membagikan data kepada pihak lain kecuali penyedia infrastruktur yang diperlukan oleh implementasi Anda, atas kewajiban hukum, atau untuk melindungi keamanan dan hak kami. Kami tidak mengklaim kepemilikan atas konten Instagram Anda.

6. Retensi dan hak Anda

Data disimpan selama diperlukan untuk fungsi aplikasi atau sampai Anda menghapusnya. Anda dapat memutus koneksi akun, menghapus kredensial lokal, meminta salinan/koreksi, atau meminta penghapusan data dengan mengikuti instruksi penghapusan data.
